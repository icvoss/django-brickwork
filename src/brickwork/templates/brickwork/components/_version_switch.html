Why this is not bw_dropdown: a version switcher carries current-version state (the trigger names the viewed version; the panel marks it with aria-current="true"), optional latest/deprecated status as text, and the consequence of picking another version (consumer-owned href routing). A menu of actions does not. ADR-091 still declines a package-owned version region; docs_header is the home for this control. No-JS floor: a native

landmark. Deliberately NO ARIA menu roles (role="menu" would promise arrow-key behaviour this floor does not provide, and version switching is navigation, not a menu of commands). No Alpine upgrade ships here; a consumer who wants typeahead composes their own enhancement. Arguments (via the tag): versions (RenderedVersion list), current_label, landmark_label / landmark_label_attr, placement (start|end). States: closed (default) and open via [open]; each version may carry status latest or deprecated (text after the label, never colour alone). Exactly one item is current. Accessibility:
landmark; current version uses aria-current="true"; status text is visible, not colour-only.
