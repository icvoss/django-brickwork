- **Header disclosures can close, and only one in a group stays open**
  (icvoss/django-brickwork#762). The account menu takes an optional `group`,
  written as the native details `name`, so exclusive open works with
  JavaScript off. `bwDisclosure` closes that menu on a pointer outside or
  Escape and plays the exit motion before `open` is removed.
  `prefers-reduced-motion: reduce` closes immediately. A content disclosure
  animates shut and does not dismiss from outside.
