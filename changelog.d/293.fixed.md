- **Wired the `code` type role** (icvoss/django-brickwork#293). `.bw-prose code` and `.bw-prose pre` bypassed the role layer, reading the raw `--bw-font-family-mono` scale step directly; `.bw-prose pre` also read `--bw-text-body-sm-size` for its font size, so retuning body copy silently moved code blocks as a side effect. Both rules now consume the `code` role's tokens: `--bw-text-code-family` (both), plus `--bw-text-code-size` and `--bw-text-code-line-height` (the block rule only). Overriding the `code` role's family, size or line-height now actually changes the render, which it previously could not. This is a visual no-op at package default in both light and dark: the role's tokens already resolved to the same values the raw scale-step reads did.
