- **A page viewed at exactly 640px now gets the wide-side styles**
  (icvoss/django-brickwork#220, ADR-079). The form grid's single-column
  collapse previously applied through 640px inclusive (`max-width: 40rem`);
  the breakpoint-token migration rewrites it as the exclusive `width < sm`,
  consistent with Tailwind's own `sm:` convention, so at that one exact
  width forms move from the stacked single-column layout to the multi-column
  layout. No other width changes behaviour; this was a convention alignment,
  not a bug fix, and pages at 639px and 641px render exactly as before.
