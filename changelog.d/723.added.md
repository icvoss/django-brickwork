- **`{% bw_asset_url %}` template tag and a `head_css` shell block** (icvoss/django-brickwork#723).
  `{% load brickwork_assets %}` exposes `{% bw_asset_url 'path' %}`, which returns
  the `{% static %}` URL for a brickwork-shipped asset with a `?v=<installed
  brickwork version>` cache-buster appended. The shell (`brickwork/shell/base.html`)
  now wraps its stylesheet `<link>` in an overridable `{% block head_css %}`, so a
  consumer can self-host the sheet or drive its URL from a setting without
  re-linking it (the DEBUG duplicate detector forbids a second link).
