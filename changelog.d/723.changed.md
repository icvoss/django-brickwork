- **The shell versions its own stylesheet URL** (icvoss/django-brickwork#723). The
  default `brickwork/shell/base.html` link now resolves to
  `brickwork/dist/brickwork.css?v=<brickwork version>` instead of the bare path.
  On a consumer whose static storage does not hash filenames (for example
  whitenoise `CompressedStaticFilesStorage`) behind a CDN or nginx that caches
  `/static/` as immutable, a brickwork upgrade previously kept serving the stale
  stylesheet until the cache expired; the version query changes the URL on every
  upgrade and is stable between them. Hashing storages are unaffected (the query
  is redundant there, never harmful).
